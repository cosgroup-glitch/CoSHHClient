Following v0.1.11:

- Add explored-area overlays to the minimap and world map. Left-click the exploration button to enable/disable tracking and display; right-click to start/stop a separate session layer; Shift-click for colors, opacity and optional 15–30 minute session expiry. History records the loaded area around the player, not precise line of sight. Disabled by default.
- Add total stat gain and an estimated food-eaten count to Feast Gains. Totals cover the time the window is open. Food counting uses food-meter increases, excluding initial snapshots, duplicate updates and resets; foods without an observed increase can be missed.
- Close Options when unlocking the UI and keep the combat UI visible so it can be positioned.
- Check for updates before initializing game resources/audio. Add 5-second connection and 15-second read timeouts; an unsuccessful update check allows startup to continue. These are per-operation timeouts, not a limit on the entire download.
- Report I/O warnings after retries are exhausted, keeping temporary failures quiet while preserving the final error and earlier causes.

Exploration settings are stored separately from game/map caches. Unreadable or malformed exploration files are reported and left untouched; no cache clearing, repair or migration is included. Inventory Manager, warehouse and sharing development remain on `test`.

Validation includes packaged feature checks for exploration persistence/session resets/expiry and failed reads, food-counter refresh handling, updater timeouts/startup behavior, and I/O retry reporting, plus the v0.1.11 regression suites. Interactive map controls and UI positioning still need broader gameplay feedback.
