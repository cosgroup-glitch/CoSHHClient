Bug fixes following v0.1.10:

- Show a purple placeholder when a world object's main resource fails to load, keeping the object visible instead of crashing. Hover text identifies the missing resource. This does not cover terrain or inventory icons.
- Detect corrupted client program archives during startup and packaging, with a clear error identifying the damaged file.
- Fix a concurrent object-label rendering crash that could occur when displaying several objects' information.
- Avoid reporting an interrupted finalizer wait as an unexpected cleanup error, while continuing to report real cleanup failures.

Purple placeholders activate only on resource-load failure in normal launches; cupboards render normally. No cache clearing or repair is part of these fixes. Inventory management and warehouse development remain on the test branch.

Validation: archive/finalizer and drawable regression checks, 24,000 concurrent label lookups, packaged archive verification, and user-confirmed placeholder appearance in the game.
